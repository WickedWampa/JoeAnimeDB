# Import Improvements

## Sync Existing Entries

Status: Planned (Post-5.0)

### Current behavior
- Adds new anime
- Skips existing entries

### Proposed enhancement
Add an optional **Sync Existing Entries** mode.

### Fields to update
- Status
- Episode Progress
- Score
- Rewatch Count

### Fields to preserve
- Notes
- Custom Tags
- Favorites
- Personal metadata

### Reason
Keep the current importer extremely fast while providing an optional synchronization workflow for MAL/CSV imports.
