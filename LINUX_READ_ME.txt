JOEANIMEDB 5.0.0 BETA 6 — LINUX

DOWNLOAD OPTIONS
- JoeAnimeDB-5.0.0-beta.6.AppImage
  Portable and recommended for most x86_64 Linux distributions.

RUN THE APPIMAGE
1. Download the AppImage.
2. Open its Properties and allow it to run as a program.
   Or run:
     chmod +x JoeAnimeDB-5.0.0-beta.6.AppImage
3. Double-click the AppImage or run it from a terminal.

PERSONAL DATA
JoeAnimeDB stores its database, backups and logs in Electron's per-user Linux
data folder, normally:
  ~/.config/JoeAnimeDB/

Application updates replace application files only. Your library and JoeAI
data remain in the local data folder.

CURRENT SUPPORT
- Linux x86_64
- AppImage package
- Automatic updates

Linux ARM64 is not included in this beta.
