\# JoeAnimeDB 5.0 Beta 11



Beta 11 introduces the first Android build of JoeAnimeDB alongside the existing Windows and Linux releases.



\## Android beta



\- Native Android package powered by Capacitor

\- Responsive mobile navigation and layouts

\- Local SQLite library storage

\- Library import and export support

\- JoeAI, Discover, Anime DNA, Following, Upcoming, and Analytics

\- Six visual themes

\- APK installation without Google Play



The Android version is an early beta. Some screens may continue receiving layout and performance improvements as testing expands across more phones and tablets.



\## JoeAI and Discover



\- Restored complete metadata for newly discovered recommendations

\- Improved poster, year, episode, score, and provider ID handling

\- Added regression coverage for catalog recommendations

\- Improved progressive loading and mobile responsiveness

\- Reduced duplicate and repeated recommendation results



\## Library portability



\- MyAnimeList XML import and export

\- AniList JSON and CSV import and export

\- Watch status, scores, episode progress, rewatches, dates, notes, tags, and priority are preserved when available



\## Desktop



Windows and Linux remain fully supported. Existing desktop libraries and JoeAI data are preserved during application updates.
