JoeAnimeDB Hidden Gems Root-Cause Fix

Root cause:
- Jikan/catalogService supplied `members`.
- SQLite anime_catalog did not store `members`.
- Reloaded catalog entries therefore had members=0.
- Hidden Gems treated zero/missing member data as low popularity.
- It consequently returned the same top-scored items as Highest Rated.

Fix:
- Persist members in anime_catalog.
- Add migration-safe members column.
- Keep members during catalog upserts.
- Hidden Gems now requires real low-audience data or a low popularity rank.
- View All > Hidden Gems uses the same rule.

After replacing files:
1. Restart npm run dev.
2. Click Fetch More Titles once or Update Database to repopulate member counts
   on catalog entries fetched from Jikan.
3. Highest Rated and Hidden Gems will diverge as member data is restored.
